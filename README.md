# Moustafa Abdelrahim | Portfolio

Personal portfolio website showcasing my front-end projects, skills, and background.

**Live site:** https://moustafa-abdelrahim.netlify.app

## Features

- Responsive layout for desktop and mobile
- Smooth scrolling and reveal animations
- Projects section driven by a simple data file
- Downloadable CV
- Contact links (email, GitHub, LinkedIn)

## Built with

- React
- Tailwind CSS
- Vite
- Lucide React and React Icons

## Run locally

```bash
git clone https://github.com/moustafaabdelrahim01/portfolio.git
cd portfolio
npm install
npm run dev
```
